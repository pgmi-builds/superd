## Trap found during Form B bring-up (recorded for the line)

`npm install` in the adapter **materialized the `file:../agent-hub` dependency as a physical directory copy** inside `agent-pi/node_modules/@pgmi-builds/`. The ctx0-side hub state (registerHostMount / roster / foreign target) then lived in the dead copy while the world-side mount row read the real hub — symptom: the world's virtual `webServer` never appeared (`9 entries did not activate`, all pending on webServer). Fix = replace the physical copy with the codex-style symlink (`ln -sfn ../../../agent-hub`), same discipline as the `@deepseek-ai/*` heal. Re-link after any `npm install` in this package.
